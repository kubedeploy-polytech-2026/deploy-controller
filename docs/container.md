# Контейнер

```bash
make image smoke
```

Образ запускается от `65532:65532`. Для работы нужны writable `/tmp` и
постоянный том `/state`; корневая файловая система может быть read-only.
Ключ App и kubeconfig передаются read-only томами. Ключ должен читаться UID 65532.
Переменные App те же, что при локальном запуске; `KUBECONFIG` указывает на файл
с контекстом `k3d-kubedeploy`, доступным из контейнера.

Внутри: gh 2.103.3, kubectl 1.36.5, score-k8s 0.19.0, git, make, bash, curl и Python.
Score и kubectl пересобираются Go 1.27.3 с x/net 0.60.0. Источники и gh проверяются
по закреплённым SHA256. CI проверяет amd64/arm64 и Trivy.

Публикация образа и установка в кластер добавляются отдельно.
