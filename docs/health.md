# HTTP-проверки

`--health-address=:8081` включает `GET /healthz` и `GET /readyz`.
По умолчанию HTTP-сервер выключен.

`healthz` возвращает 200, пока работает HTTP-сервер процесса.
`readyz` возвращает 503 до первого успешного опроса и после ошибки опроса;
следующий успешный опрос возвращает 200. Длительное выполнение сохраняет
результат предыдущего опроса. Завершённый деплой с ошибкой не означает сбой
самого контроллера. Ответы не содержат деталей ошибок или реквизитов.

В Kubernetes `healthz` используется для startup/liveness, `readyz` — для readiness.
Проверки подключаются в `platform` после публикации нового образа.
